How It Works

Four-step IoT and machine learning workflow

🌱

1. Sensor collection

IoT sensors collect pH, temperature, water level, and EC nutrient data.

📶

2. ESP32 transmission

ESP32 sends readings over Wi-Fi to the monitoring interface.

📊

3. ML pattern analysis

The machine learning model identifies abnormal sensor relationships.

🔔

4. Alerts and guidance

The system generates severity labels and maintenance recommendations.
